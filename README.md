# Desenvolvimento Web

Este repositório reúne uma coleção de pequenos projetos e exercícios voltados ao desenvolvimento web, usando principalmente PHP, HTML, CSS e JavaScript. Cada pasta é um projeto independente que exemplifica um conceito ou funcionalidade distinta.

---

## 📁 Estrutura de Pastas

- **agenda-app/**  
  📅 Um sistema simples de agenda em PHP, com CRUD de compromissos armazenados em arquivo ou banco de dados leve.  
  **Tecnologias:** PHP, HTML, CSS

- **assignments-2202/**  
  📝 Conjunto de atividades do dia 22/02 em PHP, incluindo manipulação de formulários e lógica de apresentação.  
  **Tecnologias:** PHP, HTML, CSS

- **db-form-app/**  
  🗄️ Formulário web que recebe dados do usuário e persiste em banco de dados (MySQL).  
  **Tecnologias:** PHP, HTML, CSS, MySQL

- **letter-generator/**  
  ✉️ Gera “cartas” customizadas a partir de um template, com upload de imagens e download em PDF/HTML.  
  **Tecnologias:** PHP, HTML, CSS, (biblioteca de geração de PDF)

- **php-basics/**  
  📚 Exercícios básicos de PHP: arrays, funções, estruturas de controle e manipulação de arquivos.  
  **Tecnologias:** PHP

- **wiki-project/**  
  📖 Protótipo de uma Wiki simples: cadastro de páginas, edição e listagem via interface web.  
  **Tecnologias:** PHP, HTML, CSS, JavaScript

---

## 🚀 Como rodar cada projeto

1. Instale um servidor local (XAMPP, WampServer, MAMP ou similar) com PHP ≥7.4 e, se necessário, MySQL.  
2. Copie a pasta desejada para o diretório `htdocs` (ou `www`) do seu servidor local.  
3. Acesse no navegador:
http://localhost/<nome-da-pasta>/

4. (Opcional) Se o projeto usar banco de dados, crie o schema e ajuste as credenciais no arquivo de configuração.

---

## 🛠️ Tecnologias e Ferramentas

- **Back-end:** PHP  
- **Front-end:** HTML5, CSS3, JavaScript (vanilla)  
- **Banco de Dados:** MySQL (em projetos que usam persistência)  
- **Extras:** Biblioteca de geração de PDF, formulários, manipulação de arquivos
